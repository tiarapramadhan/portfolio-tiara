# Tiara Putri Ramadhani — Data Science Portfolio

Personal portfolio website showcasing my journey as a Data Science student — projects, technical skills, and professional experience in data analytics, data engineering, and data science.

**🔗 Live site:** [portfolio-tiara-putri-ramadhani.vercel.app](https://portfolio-tiara-putri-ramadhani.vercel.app)

## About

I'm a Data Science undergraduate at Cakrawala University, focused on data analytics, data engineering, and data science. This site is where I document the projects I've built, the tools I use, and the experience I've picked up along the way — from internships to organizational work.

## What's inside

- **Projects** — data analysis, dashboards, and database projects, organized by category (Data Analyst, Data Engineer, Data Scientist), each with tools used, related files, and links to the source repos
- **Skills** — soft skills, technical skills, and a full tech stack (languages, libraries, platforms, tools), grouped by category
- **Experience** — internships, organizational involvement, and education, with responsibilities and achievements for each
- **Contact** — a direct way to reach out for collaboration, internships, or freelance work

## Features

- 🌗 Dark / light mode
- 🌐 Bilingual — Indonesian & English
- 🔗 Skills link directly to the projects and experience they were used in
- 📱 Responsive, works on mobile
- 🎵 Optional ambient lofi music (off by default)

## Tech stack

Built with vanilla HTML, CSS, and JavaScript — no framework. Content (profile, projects, skills, experience) is managed through Google Sheets and pulled in live, so the site updates without needing a redeploy for content changes. Hosted on [Vercel](https://vercel.com).

## Let's connect

Open to internship, full-time, and freelance opportunities in data. Reach out through the contact form on the site, or find my socials in the footer.
